# Watch Together

A tiny, private, mobile-first watch-together room for **two or three people**.
Create a room, share the 6-character code, pick something to watch, chat, and
keep playback in sync. No accounts, no uploads, no media library.

Built with plain **HTML5 + CSS3 + vanilla JavaScript + Supabase + WebRTC**.
No React, no Next.js, no bundler. The whole thing is a handful of static files.
